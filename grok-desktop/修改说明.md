# Grok Desktop 修改说明

日期：2026-07-29

## 新增项目

在 `D:\\mx\\grok-desktop` 创建了独立的 React + Tauri 2 桌面端工程。该工程与 `grok-build-main` 分离，避免在上游同步的 Rust workspace 中引入 Node.js、Tauri 或打包产物。

## 实现内容

### 前端

- 新建深色工程控制台风格的 React 界面，包含工作目录选择、服务状态、聊天区域、流式文本展示与活动记录面板。
- 新建 ACP WebSocket 客户端：连接本机 `grok agent serve` 服务，发送 `initialize`、`session/new`、`session/prompt` 和 `session/cancel` 请求。
- 新建 ACP 事件解析器，已支持文本流、基础工具活动和回合完成事件；未知事件会安全忽略。
- 明确提示：本应用没有登录页，不保存密钥，使用现有 `.grok` 或环境变量凭据。

### Tauri 后端

- 新建 `AgentRuntime`：随机选择 `127.0.0.1` 端口，生成 48 字符一次性密钥，启动资源目录中的 `grok.exe agent serve`。
- 提供 `select_workspace`、`start_agent` 和 `stop_agent` 三个受限 Tauri command。
- 工作目录必须存在且为目录；应用退出时 `Drop` 会终止托管的智能体进程。
- 配置 Windows NSIS 安装包、WebView2 bootstrapper、严格 CSP 和最小原生权限。

### 打包资源

- 新增 `scripts/copy-grok-binary.ps1`，将现有 `xai-grok-pager.exe` 复制为 Tauri resource：`src-tauri/resources/grok.exe`。
- 已在本机复制可用的 release 二进制到资源目录。
